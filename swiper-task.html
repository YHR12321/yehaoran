六种效果随心换effect 参数 + 进阶：按钮实时切换

改一个 effect 参数，轮播立刻换一种"性格"：slide / fade / cube / coverflow / flip / cards。上面的 6 个按钮已经绑好了点击事件（读取 btn.dataset.fx），JS 还需要你补两段。

✍️ 任务 4 要求

基础分：初始化 #wySw4，实现循环 + 自动播放（3.2 秒）+ 圆点分页器（#wyPag4），初始效果为 'slide'，动画时长 800 毫秒。

进阶分：补全按钮点击事件中的 TODO——实现点击按钮切换效果。提示：Swiper 动态换 effect 不能只改参数，需要先销毁旧实例再重建（destroy + new）。

⭐ 验证标准：基础分——轮播自动翻页；进阶分——点 cube 按钮变 3D 立方体、点 fade 变淡入淡出

二

creative 创意效果 · 电影选片墙effect:'creative' + creativeEffect 自定义变换

像电影网站的"选片墙"：当前海报居中，上一张缩小、向左退场并带旋转角度，下一张放大后从右侧滑入进场。全部通过 creativeEffect.prev / next 的 translate / rotate / scale / opacity 自定义。

✍️ 任务「二」要求

初始化 #wySw6，使用 effect:'creative' + creativeEffect 实现：① 上一张缩小（scale:0.75）、向左移动（translate 负向）、旋转（rotate:-12°）；② 下一张放大（scale:1.18）、从右侧进场（translate 正向）；③ 无缝循环 + 自动播放 + 圆点分页器。

⭐ 验证标准：翻页时上一张向左缩小旋转退场、下一张从右侧放大进场、循环自动播放、点圆点可跳转

三

parallax 视差效果 · 爱达·魔都号光影展parallax:true + data-swiper-parallax 系列属性

给轮播加上"景深"：parallax: true 开启视差后，幻灯片内带 data-swiper-parallax 属性的元素会以不同速度跟随切换移动——图片向左视差移动、标题向右错位滑入。本页展品：爱达·魔都号，首艘国产大型邮轮，2024年1月首航。

✍️ 任务「三」要求

初始化 #wySw7，开启 parallax: true；图片标签加 data-swiper-parallax="-200"，标题文字加 data-swiper-parallax="100"，实现图片与文字反方向错位的视差效果；展品为爱达·魔都号（首艘国产大型邮轮，2024年1月首航），图片为 16:9 横版。

⭐ 验证标准：切换时图片与标题以不同方向、不同速度错位移动，产生明显视差景深感
